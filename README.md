# 💳 Simple C++ Payment System (OOP-Based)

This is a basic console-based payment system written in C++ using Object-Oriented Programming (OOP) concepts. It allows an admin to manage customers and perform basic financial operations.

## 🚀 Features

- Add new customers (with ID, name, and initial balance)
- View all customers
- Update customer name
- Delete customers
- Transfer money between customers
- Prevent duplicate customer IDs
- Console feedback with colored output

## 🛠️ Technologies

- C++
- Standard Library (`iostream`, `vector`, `string`)
- ANSI Escape Codes for terminal color output

## 📦 How to Run

1. **Compile the program:**
    ```bash
   g++ -o payment_system main.cpp

3. **Run the program:**
    ```bash
    ./payment_system
